# Vortex Industries — official site

The public page for everything under this account, served by GitHub Pages at
**https://athallajovian9-cyber.github.io/**

**Official source:** this repository, and the
[Vortex Industries Discord](https://discord.gg/QtyBucygQ6). Anything found elsewhere is not ours and
has not been checked.

## What is in here

- **`index.html`** — the whole site. One file, no framework, no build step.
- **`Play_Game.vbs`** — a personal Windows launcher. It opens a local HTML game in
  Chrome app mode, frameless, from a fixed path on one machine. It is not part of
  the site and is not meant for anyone else to run as-is.

## The page lists

- **Vortex tools** — the Windows tuning utilities
- **Macros** — the Roblox automation projects
- **Games** — the browser and desktop games
- **Other** — the rest

## Deploying a change

GitHub Pages serves whatever is on the default branch. Edit `index.html`, commit,
push. Nothing else runs.

## Notes

- Static only. No backend, no analytics, no dependencies.
- The tools and macros are downloaded from their own repositories' Releases pages,
  not from this site.
- Questions: the [Discord](https://discord.gg/QtyBucygQ6).

## Disclaimer

The tools linked from this site change real Windows settings. Read what a tool
does before running it. Provided as is, with no warranty.
